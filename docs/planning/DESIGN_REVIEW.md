| 优先级／范围 | 尚缺的答案 | 应产生的记录与推进方式 |
| --- | --- | --- |
| P0 游戏基础 | 自动截止时间、自动和牌与跨局恢复的实场覆盖 | [阶段 1 实场](../validation/phase1-live.md)已补采集、完整同步、普通弃牌和最终暂停；[自动读回](../validation/automation-gates.md)、[跨局协调](../validation/lifecycle-coordination.md)及阶段 2 动作已有离线实现，新增实场验收待完成 |
| P0 引擎 | Akagi arm64 构建、模型来源、CPU 预算与完整动作映射 | 固定依赖与模型摘要，记录实际结果；不能把 `native_bot` 当作现成 HTTP 服务 |
| P0 接口落地 | Node／TS／SQLite 版本、运行时 schema、OpenAPI 正式验证器与错误实现 | 建工程时固定工具链；正式验证 schema 与实现，再建立契约测试 |
| P1 直播基础 | B站身份、稳定消息 ID、发送回执；中文合成格式与实际播放完成 | `docs/validation/live-output.md`；模拟后实测，分别记录预演与真实交付 |
| P1 恢复与持续运行 | 未决动作、重启、同房续局、三场／60 分钟限额和 7 天清理 | recovery／soak-run 记录，保留未实场覆盖的罕见分支 |
