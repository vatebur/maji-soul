# 自动期限与自动和牌：实现与待验收门槛

2026-11-05（Asia/Shanghai）。本批完成自动期限采集、自动和牌开关读回／恢复，以及阶段 2 动作的离线实现。未进行新的服务器实场操作；此前普通弃牌的[实场记录](./phase1-live.md)保持原范围。持续自动运行仍关闭。

## 已实现

期限取自当前操作的毫秒 `time_fixed/time_add` 与同步的 `passed_waiting_time`。每次采集两次同页面、同小局、同 step 的同步，并自动识别客户端整数倒计时；通过差分核对已耗时的秒单位，拒绝仅凭房间设置或单个计数推算。当前仅接纳已知的 300＋0 房型，追加时间与暂停时间语义未验证时拒绝。

期限始终锚定同步响应时刻，扣除完整请求往返时间和 2 秒量化误差；Actor 另留 250ms 发送余量。SQLite／子进程／截图／ACK 的延迟均消耗原预算。页面最终校验使用 `performance.now()`，墙钟倒退、迟到 ACK 与重连不能重置预算。

自动和牌读取 Unity 左侧“和”的灰／绿像素。固定版本、视口、工具栏锚点和字形同时匹配才接受。关闭时在程序暂停状态最多点击一次，再截图确认；新连接必须重新取得证明。最终程序发送前重新读回，页面证明最多有效 1 秒；操作窗口含 8／9 时只交给客户端，禁止程序竞争和牌或弃牌。

当前读图适配只支持 Unity 4.0.51、2036×918 CSS 像素、DPR=1、未滚动页面。历史 11 张倒计时截图覆盖全部 0—9，实际 PNG 识别与视觉标签一致；入仓仅保留数字与“和”的脱敏字形。该证据验证识别器，不代表当前服务器时延或自动和牌已通过实场验收。

`live-sync`／`live-once` 使用自动采集，不再依赖人工秒数。报告保存两次数字／协议对照、RTT、保守期限、开关读回与发送计数；继续使用 `data/live/state.sqlite`。无法识别或证据过期返回 blocked，不靠换台账重试。命令与配置见[USAGE](../USAGE.md#受控实场单步)。

## 用户实场验收顺序

1. 在同一已授权友人房和原台账执行 `live-reconnect`，再用新的输出目录执行 `live-sync`。确认报告中两次客户端数字与已耗时一致，`countdownSource=server-sync-and-client-pixels`，自动和牌开启且有像素读回。只比较固定房型的普通独立摸牌窗口。
2. 使用 `live-once` 验证普通弃牌：一次程序发送、唯一权威 confirmed。再执行 `pauseBeforeDispatch:true` 的单步，要求 not-dispatched、发送计数不增。临近截止或人为延迟调用时允许 blocked，必须无超期程序发送；记录当前真实 RTT，不能用合成延迟测试替代实场网络证据。
3. 重载后观察关闭的“和”被自动重新开启并读回；旧页面许可、旧 timing 和旧决策必须失效，同场／小局身份及台账保持一致。
4. 在受控可和牌局面观察自动和牌，期间不人工点和牌。桥接 `read()` 的 `lastClientWin` 应对应当前 8／9 offer 和 accepted 回执，`lastOwnWin.clientWinRequestId` 对应同一个请求，权威结果为己方自摸／荣和；同期 `bridgeActionSends` 不增加。保留开启读回的时间、客户端请求、回执与权威结果，缺任何一环都不标记通过。`clientWinRequests` 单独增加不能证明自动触发。

`programPaused` 和兼容字段 `paused` 只表示程序执行器暂停；客户端自动和牌保持开启，仍可能自行和牌。交还人工后如需停掉客户端动作，在页面关闭“和”。程序不会将其计作程序发送。

## 2026-11-06 验收前修复

并行审查复现并修复了三处边界：观察最后一次处理后发生断线／排队事件时不能报告 passed；同步响应后新出现的页面故障不能被旧 ACK 清除；开关鼠标移动等待期间发生重连／换局时不能继续点击旧目标。程序在最后暂停后再处理一次入站，核对最后 drain 与 read 的 generation、pageEpoch 和 step；无法闭合就 blocked。开关点击前后都复验连接、小局和控制代际，结束／断开页面的残留绿色字形不能当作开启证明。

近截止或协议不匹配的失败报告现在保存 `timingDiagnostics` 和白名单 `browserStatsBefore/After`，包括实际采集的两次数字、协议耗时及 RTT；`verified` 只表示期限推导通过。没有完成采样或读回失败时明确为 null，不保存 raw 协议、认证、游戏 UUID 或未知附加字段。成功同步仍须核对 `countdownSource/timingEvidence`，仅有 passed 不等于自动期限已验收。

本批 TypeScript 和 221 项测试通过，失败／跳过均为 0；以上是契约与故障注入证据，新增实场结果另记。CDP 检查与物理点击不具备跨进程原子性，任何点击后的作用域变化仍会拒绝确认。
